# test-nirvana

Achieve testing enlightenment from your terminal. This is the intentionally tiny foundation;
the actual path to nirvana is still being paved.

## CLI

```sh
npx test-nirvana --name grug
```

## Library

```ts
import { reachNirvana } from 'test-nirvana';

console.log(reachNirvana({ name: 'grug' }));
```

## Development

```sh
bun install
bun run check
bun run build
```
