# Security Policy

Report vulnerabilities privately to the repository custodians. Include affected Power Versions,
reproduction steps, impact, and whether exploitation changes the observed commit aura.

Do not open a public issue for an unpatched vulnerability. Do not test against systems you do not
own or lack permission to examine. Celestial suspicion is not a substitute for a reproducible proof
of concept.

Active exploitation qualifies for the `LUNAR-OVERRIDE` procedure in `CONTRIBUTING.md`. Mercury
retrograde does not delay acknowledgement, remediation, or disclosure coordination.
