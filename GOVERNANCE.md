# Governance

The repository is maintained by custodians entrusted with technical correctness and energetic
continuity. Decisions prioritize, in order: user safety, deterministic behavior, maintainability,
test evidence, and celestial compatibility.

Routine changes require one custodian approval. Public API changes require two. Amendments to Power
Versioning or the lunar integration window require unanimous custodian consent during a waxing Moon.

When evidence and astrology disagree, reproducible evidence determines the implementation. Astrology
determines when the implementation may be pushed. This separation of concerns is constitutional.

A custodian who is personally in retrograde MAY review but MUST NOT cast the deciding vote.
